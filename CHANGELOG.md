## 0.7.0 — 2026-10-02
First public GitHub release.
- English-default Codex plugin and a separate Chinese plugin; viewer language switching.
- Original lightweight SVG identity and UI icons.
- Bilingual installation, hardware, firmware, architecture and contribution guides.
- Portable ESP-IDF 5.4.2 firmware build with pinned dependencies.
- Public marketplace, bundled Node runtime code, release archives and checksums.
- License metadata aligned with the existing AGPL-3.0 text.
- Private development history and device-specific evidence excluded.
