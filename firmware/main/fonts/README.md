# UI fonts
Generated, embedded bitmap subsets of WenQuanYi Zen Hei: 16 px, 20 px and 30 px, 4-bit antialiasing.
Font source SHA256: 79c18ebe7b811951e8311bad7103ebeae8c337ed9988ea69e8a78a66cfe029b9.
Generator: lv_font_conv 1.5.3. Regeneration tool: tools/generate-ui-fonts.py, run on the build server after installing the converter in .cache/font-tools.
The generator extracts the first TrueType face from the system TTC with Python standard-library code. It includes ASCII and the Chinese glyphs actually used by device_ui.c and ui_model.c.
